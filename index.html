FAQ

Questions, answered

Which model does NextGPT use?

The default model is gpt-oss-20b:free served through OpenRouter. You can change it with the OPENROUTER_MODEL environment variable without touching any code.

Where is my data stored?

Chats, settings, workspace history and your profile live in your browser's localStorage. Nothing is written to a database and no analytics are collected.

Is my API key safe?

Yes. The browser only ever calls /api/chat on your own server. The key is read from process.env.OPENROUTER_API_KEY and never sent to the client.

Can I deploy this on Vercel?

Yes. Push the repository to GitHub, import it in Vercel, add OPENROUTER_API_KEY as an environment variable and deploy. The included vercel.json handles routing.

Does it work offline?

The interface, your history and the theme work offline. Generating new answers requires a connection to the AI provider.
